##### Network Troubleshooting Lab

Overview

This repository documents a practical networking lab focused on understanding, analyzing, and troubleshooting common network problems.

The project was created as part of my IT learning journey and focuses on applying networking concepts through practical scenarios rather than theory alone.



Objectives



The main objectives of this project are to:



·Understand IPv4 addressing and subnetting

·Analyze DNS resolution

·Understand ARP and MAC addresses

·Analyze TCP and UDP connections

·Understand routing and default gateways

·Understand HTTP, HTTPS and TLS

·Troubleshoot connectivity problems systematically

·Document technical findings clearly



Topics Covered



·IP addressing

·Ports and sockets

·Network troubleshooting

Privacy



All network information included in the public documentation is sanitized or based on laboratory examples.

Real personal network information such as private device identifiers, MAC addresses, hostnames, public IP addresses, Wi-Fi information and other identifying data is not included.
